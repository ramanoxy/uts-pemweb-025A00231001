## 2. Deskripsi Singkat Tema
Website ini merupakan portal profil dan katalog agenda kegiatan untuk komunitas kampus **JDG (Junior Developer Group)**. Halaman utama menampilkan identitas, serta fokus belajar komunitas, sedangkan halaman agenda menampilkan daftar event teknologi lengkap dengan informasi kuota, status pendaftaran otomatis, ringkasan statistik, dan fitur pengurutan berdasarkan tanggal terdekat.
